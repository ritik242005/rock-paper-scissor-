# rock paper scissor game
A game where player competes against the computer, which makes a random move each round, until one side reaches 3 wins.

# Features
- This game start with a yes/no input where you type yes then game will start
- Takes users move as an text input (rock, paper, scissor)
- Generates a computer based choice in reutrn form the import random , using Pythons random module
- Compare both moves of the user as well as computer and the decides the winner using the conditional logic
- Tracks the score of the both player and computer for the final decision 
- Ends when player or the bot reaches 3 wins and declares the final winner
- The first to complete 3 point win the match
